# 🐾 Pawganic Supplies

A web-based pet store e-commerce system developed using PHP, MySQL, Bootstrap 5, and XAMPP. The platform allows customers to browse and purchase pet products while providing administrators with tools to manage inventory, orders, discounts, and user accounts.

---

## 📖 Overview

Pawganic Supplies is an academic e-commerce project designed to simplify pet product shopping and inventory management. The system provides a user-friendly shopping experience for customers and a comprehensive administration panel for store management.

---

## ✨ Features

### 🛒 Customer Features

* User Registration and Login

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Move the Project

Place the project folder inside:

```text
C:\xampp\htdocs\
```

### 3. Start XAMPP

Enable:

* Apache
* MySQL

### 4. Create the Database

Database Name:

```sql
pet_store_inventory
```

### 5. Import Database

Import:

```text
database/pet_store_inventoryv10.sql
```

### 6. Run the Application

```text
http://localhost/petv10
```
